This project focuses on identifying fraudulent credit card transactions using a machine learning-based classification model. Real transaction data is preprocessed and analyzed using Python libraries like Pandas, NumPy, and Scikit-learn to detect anomalies and patterns indicative of fraud.

The backend is developed using Flask, which integrates the trained ML model into a web application. The frontend is built with HTML, CSS, and JavaScript, and user authentication is handled securely using PHP. The project was hosted locally using XAMPP for testing purposes.

The system can classify transactions as "legitimate" or "fraudulent" in real time and is designed to help financial institutions reduce fraud-related losses and improve transaction security.
